# Security Policy

## Supported versions

| What | Supported |
| --- | --- |
| `obstack` 0.1.x | ✅ |
| `main` branch of this repository | ✅ |
| Anything older | ❌ |

Fixes land on `main` and, for the SDK, in the next PyPI release. There are no long-lived
maintenance branches.

## Reporting a vulnerability

Please report privately, not as a public issue.

- Preferred: [open a security advisory](https://github.com/atick-faisal/observability-stack/security/advisories/new)
- Fallback: email atickfaisal@gmail.com

Include what you can — affected component (server, agent, SDK, GlitchTip), the version or
commit, reproduction steps, and the impact you believe it has. This is a single-maintainer
project, so expect an acknowledgement within a few days rather than the same hour. Please
give a fix a reasonable window before disclosing publicly.

## Secrets in this repository

The stack authenticates its ingest endpoint with basic auth, so a handful of files are
credentials and must never be committed:

- `.env.lgtm`, `.env.glitchtip`, `agent/.env.agent` and every other `.env*` that is not an
  `.example`
- `*.htpasswd` — the ingest user database generated by `scripts/add-ingest-user.sh`
- anything under `backups/`, which contains `grafana.db` and GlitchTip's database

`.gitignore` already excludes all of these. The `.env*.example` files are tracked and must
stay free of real values.

**If a credential is committed:** rotate it first — regenerate the ingest user with
`scripts/add-ingest-user.sh` and redeploy — then clean the history. Rotation is what
actually closes the exposure; rewriting history alone does not, because the old object may
already have been fetched. Report it through the advisory link above if it affected a
deployment other than your own.

## Scope

The threat model here is a public ingest endpoint reachable from app hosts. Findings in
these areas are in scope: the Traefik edge configuration, ingest authentication and
routing, the Alloy agent's handling of credentials and buffered data, and the `obstack`
SDK. Vulnerabilities in the upstream projects this stack packages — Grafana, Prometheus,
Loki, Tempo, Traefik, GlitchTip — should go to those projects; issues in *how this repo
configures them* belong here.
